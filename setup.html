Руководство по настройке базы данных Supabase

1

Откройте Supabase SQL Editor

Перейдите в ваш проект Supabase и нажмите на иконку SQL Editor в левом меню (значок </> или "SQL").

Ссылка: https://supabase.com/dashboard/project/zaudyvlmxsptjinnweve/sql/new

2

Скопируйте и вставьте SQL

Нажмите кнопку ниже, откройте файл supabase_setup.sql, скопируйте весь код и вставьте в SQL Editor:

-- Нажмите "New query" в SQL Editor
-- Вставьте весь код из файла supabase_setup.sql
-- Нажмите "Run" (Ctrl+Enter)
⚠️ Файл supabase_setup.sql находится в папке с приложением (рядом с index.html)
3

Нажмите "Run"

После вставки кода нажмите зелёную кнопку Run или нажмите Ctrl+Enter. Вы должны увидеть сообщение об успехе.

✅ "Success. No rows returned" — это нормально, всё работает!
4

Откройте приложение

После успешного выполнения SQL — откройте файл index.html в браузере Google Chrome или Microsoft Edge.
